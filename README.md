# STM32_F767zi_test1_bare_metal
NUCLEO-F767ZIを中古で安くゲットしたので遊びます．  
いずれ動的にクロックを切り替えたいと思っているので，
ライブラリ使わないで，レジスタたたく練習をしたいです．  

## 目次
- [はじめに](#はじめに)
- [環境](#環境)
- [動作](#動作)

## はじめに
STM32はF303k8で触っていたので，大体はわかりますが，新しいペリフェラルとか，微妙なお作法の違いは把握し切れていません．例えば，DWTいじるときはアンロックシーケンスある事とか，さっき知りました．  

## 環境
NUCLEO-F767ZIを使用します．  
プロジェクト本体は，STM32CubeMXでコード生成を無効にして，ライブラリを全てコピーして使用します．  
CMake+Ninja+GCC-ARMの環境です．(vscodeに拡張機能を入れて作った)  
書き込みはSTM32CubeProgrammerを使用します．  
言語はCとC++を使います．  

## 動作
ユーザーLEDが3ビットカウンタの動作をします．
